# Extract parser combinator library from macro patterns


## Notes

**2026-01-13T02:04:04Z**

Implemented parser combinator library in parser_helpers: (1) parseDelimitedSequence - parses item (delimiter item)* with backtracking; (2) parseOptional - tries parser, succeeds if present or absent (no error); (3) parseRepeat - zero or more repetitions; (4) parseRepeatMin - at least N items required; (5) parseExactly - exactly N items; (6) parseChoice - try multiple alternatives with backtracking. These replace: REPEAT_BEGIN/END, LIST_BEGIN/DELIM/END, OPTIONAL_BEGIN/END, TRY/OR/END_TRY macros. Combinators use ChoicePoint API for clean state management. Enable higher-level parser specification without macros.
