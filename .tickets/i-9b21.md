   - OPTION_NONNULL_TYPE (0x80) for @nonnull annotation
   - OPTION_TYPE_MASK (0xf0) to manage type annotations

2. Type annotation accessor macros (restructs.hpp)
   - getTypeAnnotation(n) - get annotation bits from node
   - setTypeAnnotation(n, v) - set annotation bits on node
   - isOptionalType(n) - check if node has @optional
   - isNonnullType(n) - check if node has @nonnull

3. Type annotation helper functions (restructs.cpp)
   - applyOptionalAnnotation(typeNode) - mark type as optional
   - applyNonnullAnnotation(typeNode) - mark type as nonnull
   - getTypeAnnotationString(typeNode) - get annotation for error messages

- Compatible with existing vararg and IO type flags
- Can be applied to any type node at parse time
