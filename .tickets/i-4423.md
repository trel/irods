# Design MSI type signature metadata format


## Notes

**2026-01-13T01:13:12Z**

DESIGN: MSI Type Signature Metadata Format

1. METADATA STRUCTURE (C++ header file: msi_type_registry.hpp):
   - Define struct MSITypeInfo:
     * name: string (e.g., 'msiDataObjOpen')
     * num_args: unsigned int
     * arg_types: vector<string> (type signatures for each param)
     * return_type: string
     * semantics: string (e.g., 'input', 'output', 'inout')
   
2. TYPE ANNOTATIONS:
   - Basic: string, int, float, double
   - Complex: KeyValPair, GenQueryInp, GenQueryOut, dataObjInfo_t
   - Special: T_CHKSUM_OBJ, T_RESC_GRPS, T_STR_ARR
   - Dynamic: ? (for truly unknown types)
   - Nullable: type? (e.g., string?)
   - Union: (type1 | type2)

3. STORAGE FORMAT:
   - Static C++ map in msi_type_registry.cpp
   - Key: MSI function name
   - Value: MSITypeInfo struct
   - Compile-time constant (no runtime lookup cost)

4. EXAMPLE ENTRIES:
   msiDataObjOpen:
     args: [string, int] -> output (file descriptor)
     return: int
   msiGetValByKey:
     args: [KeyValPair, string] -> string (output)
     return: int
   msiExecGenQuery:
     args: [GenQueryInp] -> GenQueryOut (output)
     return: int

5. INTEGRATION POINTS:
   - getMSIFunctionDescriptors() reads from static map
   - typing.cpp validates arg/return types at compile time
   - Parser can check type mismatches before execution
