# Refactor error handling from cascade macros to explicit paths


## Notes

**2026-01-13T02:03:34Z**

Implemented explicit error propagation API in parser_helpers: ParseResult struct (node, error, errorLocation) with helper functions makeParseResult/makeParseError, isParseSuccess/isParseError, unwrapParseResult. Error reporting functions: reportParserError (add to error stack), reportParseExpectationError (formatted expected/got messages). Replaces CASCADE macro implicit error handling. Enables: better error messages, multi-error collection, explicit error checking in refactored parsers. Ready for gradual migration: existing parser functions can continue using CASCADE while new/refactored functions use ParseResult.
