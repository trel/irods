# Design optional chaining operator (?. syntax)


## Notes

**2026-01-13T12:42:27Z**

Analyzed optional chaining: syntax for safe null dereference like x?.method(). Implementation: (1) extend parser to recognize ?. operator, (2) type system: if x is optional type, x?.field propagates optionality (result is optional), (3) codegen: runtime null check before dereference, return null if check fails. Syntax sugar: x?.y == (x == null ? null : x.y). Foundation: optional type annotations (i-c7e5) + @optional/@nonnull infrastructure enable type-safe optional chaining.
