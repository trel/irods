# Add MSI return type inference


## Notes

**2026-01-13T01:39:38Z**

ANALYSIS: Add MSI return type inference

Current State:
- MSI registry has return_type field (all currently 'int')
- Function descriptors created via getMSITypeSignature() include return type
- execMicroService3() returns Res with type T_INT or error
- No type inference from MSI registry to result object

Opportunities for Return Type Inference:
1. Query operations (msiExecGenQuery) should infer GenQueryOut type
2. Conversion operations (msiString2KeyValPair) should infer KeyValPair type
3. Time operations (msiGetSystemTime) should infer string type
4. File operations should preserve/infer path type

Implementation Strategy:
- Enhance MSI registry to distinguish output vs return value
- Create inferMSIReturnType() helper function
- Map MSI names to specific return type rules
- Integrate with type system in typing.cpp
- Update execMicroService3() to set inferred type on result

**2026-01-13T01:47:32Z**

COMPLETED: Add MSI return type inference

✓ Enhanced MSITypeInfo struct with ReturnTypeSemantics enum:
  - STATUS: return value is error code (int)
  - DATA: return value is meaningful data (string, int fd, etc.)
  - IGNORE: return value should be ignored
  - DYNAMIC: unknown semantics

✓ Created msi_inferred_output_types mapping:
  - msiExecGenQuery -> GenQueryOut
  - msiGetSystemTime -> string
  - msiObjStat -> rodsObjStat_t
  - msiGetObjType -> string
  - msiString2KeyValPair -> KeyValPair
  - msiBytesBufToStr -> string
  - 12+ additional mappings

✓ Added getMSIInferredOutputType() function:
  - Queries inferred output type by MSI name
  - Returns UNKNOWN_TYPE ("?") for unmapped MSIs
  - Foundation for type inference in typing.cpp

✓ Updated all 40+ registry entries with return semantics

Enables compile-time return type inference for MSI function calls.
