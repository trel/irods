**2026-01-12T19:34:49Z**

Query type inference already implemented in typing.cpp (lines 1523-1565). Current implementation:
1. Extracts column names from N_QUERY AST
2. Builds tuple type via createTupleTypeFromColumns()
3. Wraps tuple in collection type
4. Falls back to T_DYNAMIC for unknown columns

Next phase: Integrate union types for mixed-type queries and constraint narrowing.

**2026-01-12T19:35:01Z**

Implemented union type support in constraint solver (simplifyLocally):

When tcb is a union (T_VAR with disjuncts), tries to match tca against each disjunct.
If any disjunct matches, constraint is satisfied.
If no disjunct matches, constraint fails (ABSURDITY).

When tca is a union, delegates to narrow() for constraint tracking.

This allows queries with unknown columns to produce union types that can be narrowed
when bound to typed variables.
