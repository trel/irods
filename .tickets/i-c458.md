Move all backwardCompatible flag logic out of parser into separate codepaths

**2026-01-11T03:34:49Z**

## Design: Parser Module Separation

### Current Architecture
```
parser.cpp
├── parseRuleRuleGen(..., int backwardCompatible)
│   ├── if (backwardCompatible >= 0)
│   │   └── ExprBackwardCompatible()
│   └── else
│       └── parseTermRuleGen()
├── parseActionsRuleGen(..., int backwardCompatible)
├── TermBackwardCompatible()
├── ExprBackwardCompatible(int level)
├── TermSystemBackwardCompatible(int lev)
└── ActionArgumentBackwardCompatible()
```

### Target Architecture
```
parser_dispatch.h
├── parser_new.cpp (modern syntax)
├── parser_legacy.cpp (old syntax)
└── parse_with_version(...)
    ├── if (version < 2.0) return legacy_parser(...)
    └── else return new_parser(...)
```

### Backward Compatibility Features to Move
1. Action argument parsing (no curly braces allowed)
2. Unquoted strings in action args
3. Operator precedence differences
4. Expression parsing without strict types

### Deprecation Plan
- v2.1: Warn on legacy syntax usage
- v2.2: Legacy syntax disabled by default (config option)
- v3.0: Remove legacy syntax entirely
