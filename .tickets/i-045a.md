**2026-01-13T13:45:15Z**

Implemented configuration option to disable legacy syntax. Changes: (1) added disableLegacySyntax flag to Cache struct in configuration.hpp, (2) added setDisableLegacySyntaxMode() function to set flag with logging, (3) flag defaults to 0 (legacy syntax enabled). Can be controlled via API call setDisableLegacySyntaxMode(1) to enforce modern-only syntax. When enabled, parser can check this flag and emit errors for legacy constructs. Enables per-deployment syntax policy enforcement.
